# Electronic Work Book

Программное обеспечение, обеспечивающее доступ к электронной трудовой книжке для улучшения эффективности ведения документа.

## Требования
- .NET Framework 4.7.2
- SQL Server или другая совместимая СУБД

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/vysmi/Electronic-work-book.git
Откройте проект в Visual Studio, убедитесь, что установлен .NET Framework 4.7.2.

## Установите все зависимости.

Настройте базу данных с помощью SQL скриптов или используйте WorkBooksDB.bacpac.

## Пример использования

Запустите проект в Visual Studio.

Используйте интерфейс для доступа к электронной трудовой книжке.
